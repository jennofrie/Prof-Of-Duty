# Prof-Of-Duty™ Project Brief

## Product direction

Prof-Of-Duty is a browser-native first-person tactical-shooter prototype
created and directed by **Profexor**. Its long-term target is high-quality
combat feel, strong technical art, deterministic validation, and reliable
performance using Three.js and WebGL.

## Core principles

- Build every runtime texture, mesh, animation, effect, and sound
  procedurally from project-owned code.
- Judge improvements against measurable visual, interaction, and performance
  criteria rather than unverified claims.
- Keep systems modular, deterministic, disposable, and bounded.
- Validate graphics with reproducible captures and pixel comparisons.
- Validate movement, physics, AI, and audio with dedicated probes.
- Preserve a playable fallback while advanced systems evolve.

## Current product state

The game is **playable but incomplete**. It is a technical vertical slice,
not a finished commercial release. Current priorities and delivery gates are
tracked in [ROADMAP.md](ROADMAP.md).
